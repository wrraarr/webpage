Learning outcome mapping

CLO-PLO Mapping Toolkit

Map Course Learning Outcomes from syllabi to specific Program Learning Outcome statements in the Informatics curriculum.

The category groups on this site are only a way to browse the PLO set more easily. The actual mapping task is always outcome to outcome: CLO statement to PLO statement.

What This Maps

This tool is for learning outcome alignment, not topic tagging. Faculty enter course-level learning outcomes, match each one to the most relevant PLO statements, and then review where the program shows strong coverage, thin coverage, or possible gaps.

Input

Course Learning Outcomes taken from a syllabus or entered manually by faculty.

Target

Specific 2023 Program Learning Outcome statements, not just broad themes or content areas.

Browse Layer

Eight category groups help users find the right PLO statement faster, but those groups are not the final unit of mapping.

Result

A visible map of which PLO statements are covered across courses and which outcomes may need more attention.

How It Works

  1. Enter the course and its CLOs Start with the learning outcomes listed in the syllabus. Each CLO should describe something students will be able to do, explain, analyze, create, evaluate, or apply by the end of the course.
  2. Match each CLO to specific PLO statements Use the category groups only to browse the official PLO set. The actual choice is a PLO statement, not a topic label. Most CLOs will align with a small number of PLO statements rather than an entire category.
  3. Review the course-to-outcome map The mapper shows how courses connect to CLOs and how CLOs connect to program outcomes. This makes it easier to see which learning outcomes are reinforced in multiple places and which are touched less often.
  4. Use the results as a faculty conversation tool Coverage counts can surface patterns and prompts for discussion, but the interpretation still depends on faculty judgment about wording, emphasis, and level of performance expected in each course.

PLO Statements, Grouped for Browsing

The faculty-approved 2023 PLO language remains the reference point for this toolkit. The eight groups below are only a navigation aid that helps users find the right PLO statement more quickly during mapping.

Core Knowledge

Includes PLO statements about explaining information systems, data structures, databases, user experience, sociotechnical systems, ethics, privacy, and policy.

Technical Practice

Includes PLO statements about writing and revising code, using frameworks and APIs, working with version control, prototyping, databases, cloud tools, and accessibility practices.

Data and Analysis

Includes PLO statements about using statistical and qualitative methods, evaluating data quality, building visualizations, and interpreting evidence.

Problem Solving

Includes PLO statements about framing human-centered problems, balancing stakeholder needs, testing feasibility, iterating on designs, and reasoning about scale.

Communication

Includes PLO statements about documenting work, presenting findings, and tailoring written, oral, and visual communication to different audiences.

Collaboration

Includes PLO statements about teamwork, project management, integrating expertise, responding to feedback, and handling conflict productively.

Ethics and Responsibility

Includes PLO statements about privacy, bias, accessibility, sustainability, equity, and professional responsibility in technology work.

Lifelong Learning

Includes PLO statements about independent learning, critical evaluation of technology, professional community engagement, and reflective growth.

Tips for Stronger Mappings

  1. Write CLOs as observable learning outcomes Verbs such as analyze, design, implement, compare, evaluate, explain, and critique make alignment decisions clearer than broad topic phrases.
  2. Map what students do, not only what the course covers A course may discuss many topics, but the mapping should focus on the learning outcome students are expected to demonstrate.
  3. Choose the most specific PLO statements you can defend If a CLO seems to match an entire category, the better move is usually to identify the smaller set of PLO statements that best capture the actual expected performance.
  4. Use coverage views to prompt discussion, not to end it Strong mapping work still depends on faculty interpretation of wording, emphasis, and depth across courses.
